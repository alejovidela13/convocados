# ⚽ Convocados

Convocados es una plataforma web gratuita destinada a facilitar la organización de partidos de fútbol, la búsqueda de jugadores, la formación de equipos y la gestión de reservas de canchas.

El proyecto está inicialmente orientado a Rivadavia, Mendoza, Argentina.

## Objetivos

- Facilitar la organización de partidos de fútbol.
- Conectar jugadores y equipos.
- Simplificar la búsqueda de jugadores para completar vacantes.
- Digitalizar la gestión de reservas de establecimientos deportivos.
- Fomentar el compromiso, la responsabilidad y el juego limpio.

## Funcionalidades principales

- Registro e inicio de sesión.
- Creación y búsqueda de partidos.
- Invitaciones mediante WhatsApp.
- Participación de jugadores invitados.
- Gestión de equipos permanentes.
- Solicitudes de participación individuales y grupales.
- Sistema de reputación y calificaciones.
- Consulta de canchas y establecimientos.
- Reservas de turnos.
- Agenda digital para administradores.
- Gestión de turnos fijos semanales.
- Recordatorios de reservas.

## Arquitectura

Se plantea una arquitectura monolítica modular organizada en capas, separando la presentación, la lógica de negocio y el acceso a datos.

## Principios del proyecto

Convocados busca ofrecer una plataforma gratuita, accesible, sencilla y segura, priorizando el uso de tecnologías libres y herramientas sin costo.

La plataforma no realizará transacciones financieras ni cobrará comisiones por las reservas.
